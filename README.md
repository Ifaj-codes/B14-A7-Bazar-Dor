# Bazar Dor Application

This is a web application built for tracking daily commodity and grocery prices in Bangladesh. It helps users check market rates across different categories like rice, dal, oil, vegetables, meat, and spices.

## Features
- View today's prices along with daily price changes (increase or decrease percentages).
- Category-wise product filtering (Chal, Dal, Tel, Sobji, Mach, Mangsho, etc.).
- Product detail pages with division and market-wise minimum, maximum, and average price breakdowns.
- Price sorting functionality (low to high, high to low).
- Simulated user authentication (Sign up, Sign in, Profile) using localStorage.
- Responsive layout designed for mobile and desktop screens.

## Technologies Used
- Next.js (App Router)
- Tailwind CSS
- DaisyUI
- TypeScript

## Setup Instructions
1. Clone the repository to  local machine.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open `http://localhost:3000` in  browser.
